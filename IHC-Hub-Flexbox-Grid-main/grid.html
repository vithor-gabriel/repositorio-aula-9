Como funciona o Grid?

CSS Grid é um modelo de layout bidimensional: organiza elementos em linhas e colunas ao mesmo tempo. O elemento com display: grid é o contêiner; seus filhos diretos são os itens do grid.

As trilhas são as linhas ou colunas que formam a grade. As células são os espaços entre uma linha e outra; um item pode ocupar uma ou várias células.

Definindo colunas, linhas e espaços

grid-template-columns define as colunas e grid-template-rows define as linhas. A unidade fr divide o espaço disponível em frações. gap cria o espaço entre trilhas.

.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: 80px 120px;
  gap: 12px;
}

repeat(3, 1fr) é uma forma compacta de repetir três colunas iguais. Para trilhas responsivas, minmax(160px, 1fr) define um mínimo e permite que a coluna cresça.

Linhas e posicionamento dos itens

As linhas do grid são numeradas a partir de 1. Use grid-column e grid-row para indicar as linhas inicial e final que delimitam o espaço de um item. Por exemplo, 1 / 3 ocupa o espaço entre as linhas 1 e 3, abrangendo duas trilhas.

.item-destacado {
  grid-column: 1 / 3;
}

.item-alto {
  grid-row: 2 / 4;
}

Quando um item não tem posição definida, o algoritmo de posicionamento automático o coloca na próxima célula disponível. Se os itens ultrapassarem a grade declarada, o Grid pode criar trilhas implícitas.

Áreas nomeadas

grid-template-areas permite desenhar uma grade com nomes. Cada texto entre aspas representa uma linha, e cada nome indica a área que um item poderá ocupar. Um ponto representa uma célula vazia.

Navegação
Conteúdo principal
Rodapé
.pagina {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "cabecalho cabecalho"
    "menu      conteudo"
    "rodape    rodape";
  gap: 12px;
}

.cabecalho { grid-area: cabecalho; }
.menu { grid-area: menu; }
.conteudo { grid-area: conteudo; }
.rodape { grid-area: rodape; }

Grade adaptável

Combine repeat(), auto-fit e minmax() para criar colunas que se ajustam ao espaço disponível sem precisar definir um número fixo de colunas.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
  gap: 12px;
}

Atividade: altere o número de colunas, experimente fazer um item ocupar mais trilhas e redimensione a janela para observar a grade se reorganizar.
