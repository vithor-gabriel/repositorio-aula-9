O que é Flexbox?

Flexbox é um modelo de layout para organizar elementos em uma dimensão: em uma linha ou em uma coluna. Ele é útil para barras de navegação, grupos de botões, listas e para alinhar conteúdo dentro de um contêiner.

O elemento que recebe display: flex é o contêiner flexível; seus filhos diretos são os itens flexíveis. As propriedades de alinhamento e distribuição são definidas principalmente no contêiner.

Eixo principal e eixo transversal

flex-direction define o eixo principal: row organiza em linha (padrão), column em coluna. O eixo transversal é perpendicular ao principal. Se a direção mudar, os eixos também mudam.

.container {
  display: flex;
  flex-direction: row; /* ou column */
}

justify-content distribui os itens no eixo principal; align-items alinha os itens no eixo transversal. Seus efeitos dependem de flex-direction.

Três
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Use gap para criar espaço entre itens sem adicionar margens individuais. Outros valores úteis de justify-content incluem center, flex-start, flex-end e space-around.

Quebra de linha e itens flexíveis

Por padrão, os itens tentam permanecer na mesma linha. Com flex-wrap: wrap, eles passam para outra linha quando falta espaço, o que ajuda a criar grupos adaptáveis.

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.item {
  flex: 1 1 140px;
}

A forma abreviada flex combina três comportamentos: crescimento (flex-grow), redução (flex-shrink) e tamanho-base (flex-basis). Em flex: 1 1 140px, cada item pode crescer e encolher, partindo de 140px.

Controle por item

align-self substitui o alinhamento transversal de um item específico. order altera a ordem visual, mas não a ordem de leitura e navegação; use com cuidado e mantenha uma sequência lógica no HTML.

Quando escolher Flexbox?

Escolha Flexbox quando a organização principal acontecer em uma direção e o tamanho do conteúdo puder influenciar a distribuição. Para controlar simultaneamente linhas e colunas de uma composição, considere CSS Grid.
